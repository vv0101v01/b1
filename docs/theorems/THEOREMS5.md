## T181 4 維弦圖高斯馬可夫 ⇒ 8 維八元數公理（strmark.mbt）

**定理（計算導出，含蘊含鏈）**

1. **高斯馬可夫消沒 ⟺ 二次型黏合**：可分解圖（cliques {0,1,2}∪{2,3}，separator {2}）的精度矩陣 K 於非邊 (0,3) 消沒，且對所有 81 個 x ∈ {−1,0,1}⁴：xᵀKx = q_{C1} + q_{C2} − q_S。兩條件等價——**馬可夫性就是弦圖的「黏合」運算**。
2. **伴隨恆等式**：K·adj(K) = det(K)·I₄（精確整數，4×4 顯式）。
3. **弦圖交換律**：(F⊗G)(H⊗K) = (FH)⊗(GK)（2×2 升 4×4 區塊，精確整數）。
4. **Cayley–Dickson 升維 ℂ→ℍ→𝕆**：八元數乘法由 CD 公式 (a,b)(c,d) = (ac − d̄b, da + bc̄) 遞迴構造；**交替律**：(eᵢeᵢ)eⱼ = eᵢ(eᵢeⱼ)、(eᵢeⱼ)eⱼ = eᵢ(eⱼeⱼ) 對全部 8×8 基底組合成立。
5. **範數乘法**：|xy|² = |x|²|y|²（基底 ± 組合全檢）。
6. **蘊含鏈（本題核心）**：4 維弦圖高斯馬可夫結構 + 交換律 ⇒ 8 維八元數合成代數公理（交替＋範數）——`markov_implies_octonion_ok()` 全鏈可執行驗證。

**衍生演生法（T181′）**：以弦圖網路基因編碼；演化以「黏合誤差 + 交換律誤差」為 fitness，收斂到 CD 升維解。

## 探索中發現的新定理（計算反例/糾錯）

1. **馬可夫性 = 弦圖黏合**：精度矩陣的條件獨立（非邊消沒）與二次型的黏合分解是同一恆等式；這給出「4 維馬可夫 ⇒ 8 維八元數」鏈的第一環。
2. **交替律的 CD 來源**：八元數交替律不需要 Fano 平面表——由 ℂ→ℍ→𝕆 的 CD 遞迴自動成立（128 基底三重積實測）。
3. **導子-深度-超尖點的三角**：(Z/25)^* 的深字元計數 16 = 20 − 4 與 F_{25}^* 的超尖點軌道 10 = (q²−q)/2 是同一枚硬幣的兩面（分歧過濾 vs Galois 軌道）。
4. **單值探針**：[F,N] = 0 ⟺ N = 0（similitude F）——非半單性可由交換子探測，無須分類定理。
5. **匹配 = 雙路徑一致**：卡萊塔型匹配的可執行版本：誘導和與 Chebyshev 遞推兩條獨立路徑的恆等（本批最深的「計算機抽象」）。
6. **波前的有界/無界二分**：WF 的方向定義只在 |λ| → ∞ 有意義——離散模型必須顯式分離「增長頻率」與「有界支撐」。
