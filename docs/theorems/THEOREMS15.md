## 三個必須記住的技術點

1. **`b14_cx` 的度約定含底部 0 維**：`dims[0] = 0` 是 −1 度，`diffs[q]` 是 q−1 → q。
   任何映射錐／懸掛計算都必須先把鏈映射底部補一個 0 度零塊（`b15_map_susp`），
   否則 `f.blocks[0]` 會落到索引 −1 而**靜默丟失**——不報錯、只是答案錯。
   T495 先踩了這個坑（b/c = false），補 0 度後 n = 2 全 true。
2. **`b14_cx_ok` 的 δ² 檢查原本是空的**：舊版把乘積寫成 `d^q · d^{q+1}`（應為 `d^{q+1} · d^q`），
   而且只有兩度複形時根本沒有 q 可檢。T487 在 3、4 成員覆蓋上做了真檢定並修正。
3. **覆蓋依賴性是真的**：圓環覆蓋 [13,14] 給 H* = [1,1]，這是 S¹ 的**真同調**，
   不是缺陷；缺陷是退化覆蓋 {2}∪X 給 [1,0]。批次十四報告行 T463 的措辭已據此修正
   （舊措辭把正確答案誤記成失敗證據）。

## 一個被反證法擋下來的猜想

設計 T491 時曾猜「K₀ 應有撓，因為 RP² 的撓同調」。反證法：若 K₀ 有撓，
則某條關係的整係數組合必落在撓部分，但 `b14_snf` 給出的不變因子全為 1（無撓），
且 χ̃ 在每條關係上取 0 已把六個生成元壓成 ℤ。故 K₀ ≅ ℤ，RP² 的撓在 χ̃ 下不可見——
這正是 χ̃ 只用有理同調的原因，也是報告行 T491 保留的結論。
