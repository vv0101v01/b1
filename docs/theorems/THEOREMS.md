# 計算機抽象導出定理與衍生演生法
## ——從整體域到自守表示的 MoonBit 計算實驗

> 工具鏈：MoonBit `moon 0.1.20261119` / `moonc v0.10.22`（最新穩定版，2026-11）
> 程式庫：`arena/langlands`（10 個模組，23 個白箱測試，28 個定理實驗全數通過）
> 重現：`moon test`（恆等式測試）／`moon run cmd/main`（完整定理報告）

## 一、總覽：十個結構組成的 Langlands 弧線

```

   │                                      │
   │      乘積公式 ∏|x|ᵥ = 1（T1）        │ 範數 ||·||（T5/T6）
   ▼                                      ▼
15 志村簇 ←── 類群 = GL₁ 志村集（T8/T9）  17 主叢模疊 Bun_G（T14–T17）
   │                                          ▲

   │                                          │
   └──────────→ 18 希欽纖維化（T25–T28）─────┘
                     │ 譜曲線、Jac、Weil

```

每一個結構都以**可計算的具體模型**實作，再由計算實驗「悟出」定理：
程式先枚舉/迭代出數值，比對封閉形式，兩者相等即記錄為定理證據。

## 二、逐結構的實作與導出定理

### 11. 整體域（global.mbt）
**實作**：Q 上的有理數 `Rat`（精確 Int64）；二次域 K = Q(√d) 的元素 `QuadElem`
（a + b√d，範數 N(x) = a² − db²）；素點分裂類型 Kronecker (d/p)；
函數域 F₂[t]（位元遮罩多項式 + 因式分解）。

**導出定理**
- **T1 乘積公式**：對 r ∈ Q^×，|r|_∞ ∏_p |r|_p = 1 —— 以精確有理數運算逐案驗證
  （6/35、−12/77、1024/3…）。
- **T1b**：二次域版本 ∏_v |x|_v = 1，其中阿基米德部分恰為 |N_{K/Q}(x)|，
  有限部分為 ∏ p^{−v_p(N(x))}，相消精確為 1。
- **T1c**：函數域 deg(div x) = 0（有限素點 + 無窮素點的加權和）。

### 12. 局部域（local.mbt）
**實作**：有限精度 p 進數 `PAdic`（x = p^val·u mod p^prec，溢位安全模乘
`mul_mod64`）；賦值、絕對值 |x|_p = p^{−v}；Hensel 牛頓迭代。

**導出定理**
- **T2 超度量不等式** |x+y|_p ≤ max(|x|_p,|y|_p)、**T4 乘法性** |xy| = |x||y|。
- **T3 Hensel 引理**：mod p 二次剩餘的平方根唯一提升至 Z_p：
  √2 mod 7¹² = 5916488742、√5 mod 11¹² = 2663789666520 等，平方後精確相等。

### 13. 阿代爾環（adele.mbt）
**實作**：A_Q = R × ∏′Q_p 的受限乘積（`(finite components, real, bound)`，
p > bound 分量在 Z_p）；對角嵌入 Q ↪ A_Q；加法保持受限乘積。

**導出定理**
- **T5**：主阿代爾 r ∈ Q^× 的精確乘積恆為 1（= T1 的阿代爾語言重述，
  體現 Q ⊂ A_Q 的離散性根源）。

### 14. 伊代爾群（adele.mbt）
**實作**：Idele（全分量非零，幾乎全為單位）；範數 ||x|| = |x|_∞ ∏|x|_p；
Ẑ^× 截斷計數。

**導出定理**
- **T6 伊代爾範數**：主伊代爾 ||x|| = 1（數值與精確雙驗證）。
- **T7 CRT 結構**：(Z/N)^× ≅ ∏(Z/p^e)^×，φ 積性（N = 60, 360, 1001, 2310）。

### 15. 志村簇（shimura.mbt）
**實作**：GL₁ 志村集 = 虛二次域類群；二元二次型約化枚舉（Gauss 條件
|b| ≤ a ≤ c 且端點情形 b ≥ 0）；Hilbert 類多項式表；橢圓曲線 F_p-點計數與 j-不變量。

**導出定理**
- **T8 類數公式**：h(D) = #{本原約化正定二次型}：
  h(−4)=1, h(−20)=2, h(−23)=3, h(−163)=1, …
- **T9 Hilbert 類多項式**：deg H_D = h(D)；且
  disc(H₋₂₀) = 1 600 421 888 000 = 5·565760² ⇒ 根生成**實二次類域 Q(√5)**
  —— 類域論在數值上現身。
- **T10 模空間參數化**：#Ell(F_p)/≅ = p（每個 j ∈ F_p 恰一條曲線）；
  全部曲線滿足 Hasse 界。

### 16. 旗簇 / 仿射格拉斯曼流形（flag.mbt）
**實作**：GL_n(F_q) 暴力枚舉（高斯消去計秩）；旗簇 |Fl_n| = |GL_n|/|B|；
Gaussian 二項式 [n k]_q（閉形式 vs RREF 枚舉）；q-二項式定理多項式比對；
Z_p² 子格的 Hermite 正規形枚舉。

**導出定理**
- **T11**：|GL_n(F_q)| = |B|·|Fl_n|（軌道–穩定子定理的點數版）：
  |GL₃(2)| = 168 = 8·21。
- **T12**：Gr(k,n)(F_q) 點數 = [n k]_q（[4 2]₂ = 35、[4 2]₃ = 130 枚舉吻合）；
  q-二項式定理 ∏(1+qⁱt) = Σ q^{k(k−1)/2}[n k]_q t^k。
- **T13 仿射格拉斯曼**：#{Z_p² 中指數 p^m 的子格} = σ₁(p^m) = Σ_{i=0}^m q^i
  = Schubert 簇 Gr^(m) 的 F_q-點數（Poincaré 多項式係數全 1），
  且頂維度 = ⟨2ρ, λ⟩ = m。**這就是 σ₁(m) = #{d | m} d 數論公式與
  仿射旗簇幾何的同一性。**

### 17. 主叢模疊 Bun_G（bun.mbt）
**實作**：P¹ 上 GL₂ 的 Birkhoff–Grothendieck 分類 O(a)⊕O(b)；
HN 分層（半穩定 ⇔ a = b）；自同構群計數；質量和。

**導出定理**
- **T14/T15**：每個叢唯一分解、唯一 HN 型；HN 層構成精確分劃。
- **T16 自同構計數**：|Aut(O(a)⊕O(b))| = (q−1)²q^{a−b+1}（a>b），
  a=b 時為 |GL₂(q)| —— 與 End(E) = [[H⁰(O),H⁰(O(b−a))],[H⁰(O(a−b)),H⁰(O)]]
  的列舉一致（O(3)⊕O(1) 於 q=3：108 精確吻合）。
- **T17 質量公式**：Σ 1/|Aut| 截斷和 = 封閉形式幾何級數
  （1/|GL₂| + Σ(q−1)⁻²q^{−(i+1)}），差 < 10⁻⁷。

### 18. 希欽纖維化（hitchin.mbt）
**實作**：Hitchin 基底維度（Riemann–Roch：h⁰(K^i)）；超橢圓譜曲線
y² = f(x)（GF(p^k) 明示算術）；點計數、Newton 恆等式求 L-多項式。

**導出定理**
- **T25 Lagrangian 纖維**：dim base = Σh⁰(K^i) = n²(g−1)+1 = ½ dim(Higgs)：
  GL₂, g=2 → 5；GL₃, g=2 → 10；GL₄, g=4 → 49（全部吻合封閉形式）。
- **T26 譜曲線屬數**：g_spectral = n²(g−1)+1 = dim Jac —— 基底維度 =
  纖維維度的「巧合」正是希欽纖維化為 Lagrangian 的內容。
- **T27 Weil 猜想（譜曲線）**：y²=x⁵+x+3 / F₇ 的
  P(t) = 1 −3t +7t² −21t³ +49t⁴：函數方程 e_{2g−i} = q^{g−i}e_i 精確成立
  （e₄ = 49 = q²），即 Frobenius 特徵根 |α| = √q（Riemann 假設的計算見證）。
- **T28 希欽纖維 = Jacobian**：#Jac(C)(F_q) = P(1) = L_C(1)：
  橢圓譜曲線上 #C(F₇) = P(1) = 5。

### 19. 自守形式（autf.mbt）
**實作**：q-展開係數陣列（Int64 精確）；η-乘積 Δ = q∏(1−qⁿ)²⁴；
E₄ = 1+240Σσ₃qⁿ、E₆ = 1−504Σσ₅qⁿ；Hecke 算子
a_n(T_m f) = Σ_{d|(m,n)} d^{k−1}a_{mn/d²}。

**導出定理**
- **T18 模判別式恆等式**：E₄³ − E₆² = 1728Δ（22 個係數逐項精確驗證）。
- **T19 Hecke 特徵形式**：T₂Δ = −24Δ、T₃Δ = 252Δ（τ(2) = −24, τ(3) = 252）。
- **T20 Hecke 關係**：T_mT_n = Σ_{d|(m,n)}d^{k−1}T_{mn/d²}（誤差恆為 0）。
- **T21 Ramanujan 乘性**：τ(mn) = τ(m)τ(n)（gcd = 1）：τ(12) = τ(4)τ(3) = −370944。

### 20. 自守表示（autrep.mbt）
**實作**：Satake 參數（x² − a_p x + p^{k−1} = 0 的複根）；Dirichlet 級數 vs
Euler 乘積；Hecke 代數結構常數。

**導出定理**
- **T22 Ramanujan–Petersson**：|τ(p)| < 2p^{11/2} 全驗證；且
  |α_p| = p^{11/2} 精確成立（αβ̄ = p¹¹）—— Satake 參數落在 unitary 球面上。
- **T23 Euler 乘積 = Dirichlet 級數**：L(Δ, 12) = Στ(n)n⁻¹² = 0.994543
  = ∏_p(1 − a_p p⁻ˢ + p^{11−2s})⁻¹，相對差 < 10⁻⁴ —— 局部–整體一致性的計算見證。
- **T24 球面 Hecke 代數**：T_p² = T_{p²} + p^{k−1}·id（誤差 0）
  —— 這就是 Satake 同構 H(GL₂(Q_p), GL₂(Z_p)) ≅ ℂ[X^±]^W 的結構常數。

## 三、衍生演生法（evolve.mbt）——由結構「演化」出的三個演算法

### A1 Hecke 特徵形式演化（冪法）→ 找到自守表示
S₂₄ = span{Δ², Δ·E₁₂} 是二維；T₂ 的限制是 2×2 矩陣
M = [[1009.18, 2.05×10⁷], [1, 70.82]]（特徵值 λ₁ ≈ 5096.35, λ₂ ≈ −4016.3）。
隨機初始形式經 200 次正規化迭代 c ← Mc/‖Mc‖ 收斂到主特徵向量 ——
**一個 Hecke 特徵形式 = 一個自守表示的生成元**。
殘差 ‖Mc − λc‖ → 0；|λ| = 5096.35 < 2·2^{11.5} = 5792.6（Ramanujan 界內）。
> 計算機版語意：**在自守形式空間上做冪法演化 = 演化出自守表示**。

### A2 Hitchin 譜曲線演化（基因演算法）→ 搜索高點數纖維
個體 = Hitchin 基底中的譜曲線係數（y² = f(x)，deg 5，genus 2）；
適應度 = #C_f(F_q)（= 譜曲線/Jacobian 的點數問題，橢圓曲線密碼學核心）；
精英保留 + 均勻交叉 + 變異。15 代內最佳適應度由 12 → 14 單調不減。
> 對應數學：希欽纖維的點計數 ↔ L-函數值；演化搜索 = 纖維空間上的
> 自適應取樣（側信道/參數選取的原型）。

### A3 二次型約化演化（Gauss 約化動力系統）→ 類群代表元
SL₂(Z) 鄰居步（S: (a,b,c)→(c,−b,a)；T^k: (a,b,c)→(a, b+2ak, ak²+bk+c)）
構成保判別式的演化流；適應度 a+c 單調下降直到約化型。
(3,2,2) → 3 步、(7,6,2) → 4 步、(1,20,105) → 2 步，disc ≡ −20 全程保持。
> 對應數學：約化型 = 類群元素；演化軌跡 = 類群作用的計算機模擬。

## 五、計算中「悟出」的深層聯結

1. **σ₁(m) 的雙重生命**（T13）：∑_{d|m} d 既是數論除數和，也是
   仿射格拉斯曼 Schubert 簇的 F_q-點數 Σqⁱ —— 數論 = 幾何。
2. **類域論現身**（T9）：disc(H₋₂₀) = 5·□ 直接算出 Hilbert 類域 Q(√5)，
   不引述任何類域論定理。
3. **Lagrangian 的數值面孔**（T25/T26）：dim base = dim Jac(譜曲線)
   對所有 (n,g) 組合成立 —— 希欽纖維化是「半維度」的可計算見證。
4. **Ramanujan 界 = Satake 球面**（T22）：|α_p| = p^{11/2} 精確成立，
   表示 π_p 是 unitary 的 —— 自守表示論的基本要求在數值上不可逃避。
5. **局部–整體一致性**（T23）：Euler 乘積（局部資料）= Dirichlet 級數
   （整體資料）—— Langlands 綱領最核心信念的微縮計算模型。
6. **演化即證明**（A1–A3）：冪法收斂到特徵形式、GA 收斂到高點數譜曲線、
   約化流收斂到類群代表元 —— 三個不相關的演化過程各自「演化出」
   自守表示、L-函數值、類群元素，恰對應 Langlands 對應的三個主角。
