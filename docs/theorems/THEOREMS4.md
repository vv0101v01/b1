5. **純權重分級**：H^i 賦權 i，graded pieces 顯式驗證 (0,0),(1,0),(1,1),(2,2)。

**衍生演生法（T51′）**：以投影子網路基因編碼 Chow 環關係；演化以「各向同性誤差 ‖pᵀJp‖ + 冪等誤差」為 fitness，收斂到 Künneth 分解。

## 探索中發現的新定理（計算反例/糾錯）

1. **h-遞推 vs s-遞推**：a_{p²} 在 Hecke 世界 = a_p² − p、在 Galois 世界 = a_p² − 2p——兩者都是對的，混用必錯（本批 7 個測試失敗的根源）。
2. **X₀(11) 的 mod-5 ρ̄ 可約**（有理 5-扭 Z/5）：塞爾非平凡情形須用 ℓ = 3。
3. **p = 5 的 Hasse 提升二義**：(1, −4) 皆合法——提升唯一性只在 4√p < 5（p = 2, 3）成立；p = 5 開始需要 Galois 資料消歧。
4. **j = 0 的一般模型退化**：(j/1728)² 公式在 j = 0 得 (0,0) 奇異；光滑模型必須特設 (0,1)。
5. **節點平面模型 vs Néron**：x(y²−x) = p·f 的節點模型計數（3 at p = 11）≠ Néron 導出群點數（104）。
6. **2×2 對角元 ≠ 特徵值**：由 tr/det 解 λ 的教訓；「Euler 特徵 = 0」是錯陳述（Maschke 消滅 + Z¹ 切空間才是真相）。
