# 批次十定理目錄（T349–T380、A49–A56、H10-1–H10-6）

主題：以拓撲斯與 ∞-範疇的結構作為計算抽象——勒雷譜序列、高階直像層、∞-遺址、
高階吉羅公理、拓撲斯基本群、射影有限基本群、局部群oid、等變層、全連通／幾何滿射／
有界幾何態射、弗羅貝尼烏斯互反律、基變公式，以及索引／相對／局部化／原子／格里森／
空間拓撲斯與局部常數層。

執行方式：`moon test`（170/170）與 `moon run cmd/main`（報告含零 `[FAIL]`）。

## 計算模型

* **有限空間站**：有限拓撲空間 `X` 的非空開集族 = 站物件，包含關係 = 態射；覆蓋 = 聯集覆蓋。
* **有限預層**：`B8PS`（逐物件元素表 + 限制映射），直像 = 拉回、逆像 = 左 Kan 擴張 + 層化。
* **有限群作用**：`B9Group`／`B9GSet`，正則作用、軌道、穩定子、同構類計數。
* **Čech／神經引擎**：以子集遮罩枚舉單純形，模 `p` 高斯消去計算上同調維數。

## 框架假設（未在有限模型內證明）

* **H10-1** Galois 對應：指數 `n` 子群 ↔ 連通 `n` 度覆蓋（阿貝爾群上子群 = 共軛類，計算相符）。
* **H10-2** 等變層 ≃ 商疊／商拓撲斯上的層（以正則性與 `n+1` 計數佐證）。
* **H10-3** 離散空間的拉回 = 集合的纖維積（基變與投影公式的模型）。
* **H10-4** 有限空間拓撲斯上「`Sub(1)` 布爾」⟺「拓撲斯原子」。
* **H10-5**（框架限制）站不含空開集 ⇒ 不交覆蓋的空交集退化，`b9_sheafify` 在該情形失真；G3′ 改以象子層直接計算。
* **H10-6** Čech 神經（允許重複元組）即超覆蓋。

## 負見證（共 10 例）

1. 坍縮層在 Sierpiński 與圓上非局部常數（2 例）⇒ 局部常數判定非恆真。
2. 嚴格（無冗餘）超覆蓋條件在 3 個空間上失敗 ⇒ 超覆蓋必須允許退化（∞-遺址的必要性）。
3. 坍縮映射 `[0,0,0]` 非幾何滿射（1 例）。
4. 非離散空間上原子性失敗（3 例）⇒ 原子性判定非恆真。
5. 圓的正則開集代數非布爾（1 例）⇒ 格里森覆蓋非平凡（絕對空間非單點）。
