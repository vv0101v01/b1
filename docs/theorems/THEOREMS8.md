## 0. 本批次的方法論

第八批的主題全部是「無窮結構的有限可計算影子」。做法統一為三層：

1. **顯式有限模型**：有限範疇（物件／態射／dom／cod／id／合成表）、有限預層（逐物件有限集合＋限制映射）、
   繼承有限集（雜湊駐留）、有限單純集（面映射）、有限分佈（有理數或 1/16 網格）。
2. **精確計數**：所有定理都以「整數等式」「精確有理數」「BigInt 十進位位數」或「殘差 < 10⁻¹²」給出見證，
   不使用「取樣成立」式的歸納證據。
3. **誠實分層**：每一條定理都標明「**計算所得**」還是「**框架假設**（超出有限模型、由文獻保證）」。

核心技術突破是本批次新寫的 **Nat 集計數器**：以「插槽變數 + 自然性約束」建立 CSP，
用 AC-3 弧相容剪枝 + 最小定義域回溯，精確計算 `|Nat(F, G)|`。
它把 Yoneda、伴隨、Kan 擴張、Morita 型的範疇論陳述全部變成**可數的整數恆等式**，
而不是只能「相信」的交換圖。

## 1. 模組一：點函子與評估函子（T240–T246，`catcore.mbt`）

固定物件 c，評估函子 `ev_c : PSh(C) → Set`，`F ↦ F(c)`；它可表化為 `Nat(よ(c), −)`。
本模組把「ev_c 是點函子」的整組伴隨結構做成計數核對。

| 編號 | 定理 | 計算見證 |
|---|---|---|
| T240 | Yoneda 計數：`|Nat(よc, F)| = |F(c)|` | 7 個範疇（箭頭、平行對、走路同構、單物件 Z/2、走路餘等化子、交換方格、離散 3 點）× 隨機預層，全部成立 |
| T241 | Yoneda 嵌入全忠實：`|Nat(よa, よb)| = |Hom(a,b)|` | 同上 7 個範疇的所有物件對 |
| T242 | ev_c 保積：`|Nat(よc, F×G)| = |F(c)|·|G(c)|` | 逐物件計數相等（例：Z/2 上 8×8） |
| T243 | ev_c 保餘積：`|Nat(よc, F⊔G)| = |F(c)|+|G(c)|` | 逐物件計數相等 |
| T244 | 左伴隨 `A ⊗ よc`：`|Nat(A⊗よc, F)| = |F(c)|^A` | A = 2，逐物件相等 |
| T245 | 右伴隨 `G_A(d) = A^{Hom(c,d)}`：`|Nat(F, G_A)| = A^{|F(c)|}` | A = 2，逐物件相等（此式推出 cofree 必須用 `Hom(c,d)` 而非 `Hom(d,c)`——程式中最初寫錯，計數核對立刻抓到，是本方法有效的實例） |
| T246 | 範疇公理（單位律、合成型、結合律）與預層函子性 | 7 個顯式範疇 `b8_cat_ok` 全真；常數／可表／乘積／餘積／cofree 預層 `b8_ps_ok` 全真 |

**技術註記**：預層的行距（`mx`，即 `res` 的 stride）必須與「逐物件最大基數」一致，
否則乘積／餘積的配對編碼會越界。這一 bug 也是由 `b8_ps_ok` 與 Yoneda 計數同時抓到並修正的。

## 2. 模組二：拉回函子沿函子合成（T247–T252，`pullback.mbt`）

對函子 `u : C → D`，預層拉回 `u* : PSh(D) → PSh(C)`，`(u*X)(c) = X(u c)`。

| 編號 | 定理 | 計算見證 |
|---|---|---|
| T247 | 拉回沿合成**嚴格**相等：`(v∘u)* = u* ∘ v*` | 3 條函子鏈（箭頭→方格→Z/2、箭頭→方格×恆等、餘等化子→箭頭→方格），逐元素比較限制映射全等 |
| T248 | `u*X` 是良定義預層 | `b8_ps_ok` 對所有測試拉回為真 |
| T249 | 左 Kan 擴張沿恆等是恆等：`Lan_Id X = X` | 交換方格上逐元素相等（含所有限制映射） |
| T250 | `u_! ⊣ u*`：`|Nat(u_!X, Y)| = |Nat(X, u*Y)|` | 4 個可表預層 + 常數 1、2；計數逐項相等（0/0、1/1、0/0、1/1、1/1、8/8） |
| T251 | 左 Kan 擴張沿合成：`(v∘u)_!` 與 `v_! u_!` 的元素數相等 | 箭頭→方格→Z/2：6 = 6；餘等化子→箭頭→方格：3 = 3 |
| T252 | 複合伴隨一致：`|Nat((vu)_!X, W)| = |Nat(u_!X, v*W)|` | 兩者皆 8 |

**左 Kan 擴張的實現**（本批次新程式碼）：按預層情形使用正確的餘端公式
`(u_!X)(d) = ∫^c Hom_D(d, u c) × X(c) = colim_{(c, φ : d → u c)} X(c)`，
以併查集求等價閉包 `(c',φ',x') ∼ (c,φ,x) ⟺ ∃ψ : c → c', φ' = uψ∘φ, X(ψ)(x') = x`，
再逐物件把等價類編號，並用「代表元素沿 m 後合成」求出限制映射。
**此處一度誤用 `Hom(u c, d)`（轉置），T249（`Lan_Id = Id`）立即失效並暴露錯誤**——
這正是「定理必須有計算見證」的價值：錯誤的伴隨方向在文字論證裡很容易蒙混過關。

## 10. 五條貫穿的線

1. **「計數即證明」**：Yoneda、伴隨、Kan 擴張、層化、Morita、單純填充，全部化為 `|Nat|` 或基數的整數等式。
   Nat 集計數器（AC-3 + 回溯）是整個批次的引擎（A29），它在開發過程中抓到了三個真實錯誤：
   預層行距不一致、cofree 的 `Hom` 方向、左 Kan 擴張的餘端轉置。
2. **「穩定化」是無窮結構的有限簽名**：加號構造在 1 步穩定、鏈餘極限的穩定指數、Mostowski 崩塌的深度、
   IB 的迭代步數——都是「無窮過程」在有限模型上留下的可數特徵。
3. **「負面見證」同樣重要**：`x = {x}` 在良基宇宙 0 解、圓沒有內角填充、`V_1` 不是宇宙、
   `|GL₂(F₂)|` 中 10 個不可逆矩陣——本批次每條「否定性」陳述都附帶精確計數。
4. **範疇化 = 把數提升為結構，再退化回數**：群胚基數 χ 把範疇變成有理數，Betti 數把空間變成整數序列，
   而 `χ = Σ(−1)^i b_i`（T270）與 `χ(G×H) = χ(G)χ(H)`（T267）正是兩層之間的橋。
5. **資訊幾何與範疇幾何共用同一套「張量—Möbius」語言**：互資訊張量 `I_S` 是熵的 Möbius 反演，
   與範疇裡的 Kan 擴張公式（T250）、預層的極限公式（T242）在形式上是同一個「全子集求和」結構。

## 12. 誠實性聲明

**計算所得（本程式真的算出來、可用整數覆核）**：T240–T293 的全部數值見證；
A29–A38 的全部輸出；`b8_cat_ok` / `b8_fun_ok` / `b8_ps_ok` / `b8_site_ok` / `b8ss_identities` 的結構檢定。

**框架假設（本程式不證，僅在文中標明角色）**：
- ZFC 內部的基數理論（不可達基數存在性、`V_λ ⊨ ZFC ⟺ λ` 強不可達）；
- 一般 ∞-拓撲斯的超限層化迭代（本程式只做有限站上 1 步穩定的計算影子）；
- 一般（非有限）Morita 理論與 Quillen 模型結構；
- Joyal 的準範疇理論（本程式只驗證有限模型上的內角填充）；
- IB 的一般收斂性定理（本程式只驗證具體分佈上的定點與殘差）。

**已知限制**：
1. 有限模型只能驗證「影子」，不能證成無窮陳述；所有無限性結論都以「極限 + 精確有理數/大數」的方式間接給出。
2. 半單純集模型忽略退化映射（degeneracies），故「Kan 複形」判定只在維度 ≤ 2 與面條件層面成立。
3. Nat 集計數是精確的，但其複雜度對預層尺寸敏感（插槽數 × 候選數），因此測試預層刻意保持小尺寸。
4. 浮點資訊量只在 `1e-12` 容差下比較；精確部分（獨立性判定、整數計數）則完全不依賴浮點。
