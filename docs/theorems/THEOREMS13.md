## 本批次的態度：把「高階／無窮」降成「有限可判定」

21 個名詞中，拓撲格、內在遺址、莫里塔等價、局部閉合、基變、內部張量積等本來就有限可算；
纖維拓撲斯、n-拓撲斯、凝聚 (∞,1)-拓撲斯、譜層、扭子則涉及無窮範疇或無窮結構。
處理方式一律是——**選定一個忠實的有限模型，把該名詞的定義條件化為可反駁的等式或計數**：

| 名詞 | 有限模型 | 判定方式 |
|---|---|---|
| 拓撲格 frame | 有限拓撲空間的開集格 O(X) | meet/join 表 + 4 條公理逐項檢查 |
| 內在遺址 | 格元素索引的覆蓋族 | 反射／恆等／遞移三公理 |
| 遺址外化 | join-不可分解元素重建點集 | 往返一致性（覆蓋族的 join = 目標） |
| 莫里塔等價 | 格論指紋 (下界數, 上界數) | 指紋配對 + 保 meet/join 的雙射 |
| 擬分離態射 | 有限空間：每子集緊緻 | 逐組 (V, U₁, U₂) 計數 |
| 局部閉合分解 | A = U ∩ cl(A) | 在拓撲中搜尋見證 U（找到才算） |
| 纖維拓撲斯 | 纖維上的拉回拓撲 | 點數／開集數／連通分量 |
| 平展下降 | 逐點相容性 + 覆蓋完整性 | 常數截面必可黏合，冒充覆蓋必失敗 |
| 伽羅瓦拓撲斯 | 有限 G-集合 | G-作用公理 + 軌道分解 |
| 弗羅貝尼烏斯作用 | 置換的固定點 | |X^F| 與直和下的加性 |
| 基變定理 | φ_! ⊣ φ* 的 Hom 計數 | 左右兩邊等變同態數相等 |
| 阿廷／DM 疊 | 有限群胚 | 自同構群階 + 同構類 + 全邊可逆性 |
| n-拓撲斯 | 有限鏈複形 | 「無 k > n 的非零同調」 |
| 同倫截斷 | τ_{≤n} 截 dim/rank | 冪等性 + 低階同調保留 |
| 凝聚 (∞,1)-拓撲斯 | 有限生成投射模的秩向量 | 餘積／拉回封閉性 |
| 譜層 | 階層 → 譜序列的族 | 逐階對角收斂 + 歐拉類和 |
| 幾何順序 | 兩個 Grothendieck 拓撲的包含 | 每個覆蓋被細化 |
| 正則順序 | 上閉包 a∘a | 冪等 + 新增覆蓋數 |
| 內部張量積 | 層的點秩 | 秩相乘 + 三律 |
| 內部 Hom | 層的點秩 | 秩為 \|G\|^\|F\| + 伴隨律 |
| 扭子 | 秩—扭數對 | 單調性 + 沿態射的守恆 |

## 誠實殘餘（本批次明確標記的缺口）

1. **纖維拓撲斯**是「纖維上的拉回拓撲」，不是一般纖維積的拓撲斯；沒有計算高階直像或相對拓撲斯的內部邏輯。
2. **（∞,1)-下降**以「逐點值唯一」代替高階同倫極限；高階相容性（Čech 神經的同倫群）未實作。
3. **凝聚 (∞,1)-拓撲斯**只以有限生成投射模的秩向量為模型，沒有實作完全的凝聚對象範疇與其濾過。
4. **譜序列**只保留檢查器（A85），且其判準「表的對角線和 = 目標同調」不足以證明真正的收斂 ——
   d₂ 及 higher differentials 完全未實作，因此本批**不宣稱**任何譜序列收斂定理。
5. **扭子**以秩—扭數對的單調性為模型；與 twistor 空間（複結構／四元數結構的模空間）的幾何對應未建立。
6. **Artin／DM 疊**只做到有限群胚層級；沒有實作 2-範疇的纖維積、穩定子群疊或 moduli 的幾何性。
7. **擬分離**在有限空間上恆真（每子集緊緻），故該檢核證明的是「判準與理論一致」，而不是「找到非擬分離的例子」。
