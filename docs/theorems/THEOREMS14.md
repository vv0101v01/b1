## 本批次修掉的底層缺陷（皆有前後對照）

1. **`b14_f2_zero(rows, cols)` 參數序寫反**：所有 `diffs.push` 原寫 `f2_zero(cols, rows)`，導致每個鏈複形維數全錯；改為 `f2_zero(dims[q+1], dims[q])`。
2. **0 列矩陣不可由形狀推得**：新增 `b14_f2_kernel_n(m, ncols)`，`cx_trunc_le` 改用之；否則截斷／Hom 必 panic。
3. **`b14_hom_cx` 塊偏移錯**：改為「先固定 q、再枚舉 p」的 `b14_hom_block_base`。
4. **正交性檢定多移了一位**：`Hom(τ_{≤k}A, τ_{≥k+1}B) = 0` 不需要 `[1]` 移位；移位會把 `Hom(S⁰,S⁰)` 誤判為非零。
5. **`b14_cx_ok` 迴圈上界錯**：`d^q ∘ d^{q+1}` 只有 `q ≤ n−3` 可乘，原寫 `n−1` 會越界（Čech 複形 n = 2 時必崩）。
6. **`b14_f2_mul` 對空列矩陣越界**：inner 改以 `a[0].length()` 為準並加索引守衛。
7. **SNF 只做對角化**：diag(2,3) 原報 [2,3]，實際 SNF 為 [1,6]（ℤ/2⊕ℤ/3 ≅ ℤ/6）；已加相鄰 gcd/lcm 歸一。
8. **把截斷式 `b14_cx_shift` 當懸掛 Σ**：使「Σ 為等價」與「χ(ΣC) = −χ(C)」雙雙失敗；新增真懸掛 `b14_cx_susp` 後通過。

## 誠實標記：計算所得 vs 框架假設

**計算所得（可重跑、無假設）**：T462–T479、T481（8 組預層）、T482 的 FinSet 部分、T483、T484，
以及 A86–A95 的全部輸出。這些都是有限集合上的窮舉或整數等式。

**框架假設（未在程式中證明）**：
1. 「局部可呈現 + 小生成集」在高階吉羅公理中的地位——有限 topos 中自動成立，故程式中只是**陳述**而非檢定（T480）。
2. 「預層 topos 中有效 ⇒ 任意 topos 中有效」——只驗證了指標範疇 0 → 1 的情形（T482）。
3. ∞-層化只做到**度 1**（Čech 覆蓋）；超覆蓋與高階相容性（同倫群）未實作（T481）。
4. 反常 t-結構以「逐層直和影子」為模型——它捕捉了逐層平移，但不含真的自同構／黏合資料。
5. 「中介擴張 = 最小者」只在 b = 1, 2 的分層玩具模型上驗證；一般 IC 層的構造（含 D 模／ℓ-進係數）未觸及。
6. 動機上同調只實作了**符號群 → K^M₂ → 群結構**這一段；Voevodsky 的動機範疇、A¹-局部化、Nisnevich 下降均未實作。
7. 「穩定化」驗證的是「Σ 成為等價 + χ 為加性/乘性不變量」的有限核心；K₀ 與 Waldhausen 結構的一般陳述未證。
8. 點空間只到**有限圖的 π₁**（自由群）；高階同倫群、Whitehead 塔未實作。

## 一個被計算推翻的猜想（保留記錄）

設計初稿曾猜測 `K^M₂(F₅) = ℤ/2`、`K^M₂(F₇) = ℤ/3`（憑「有限域 K 群應有撓」的直覺）。
實作時以完整的符號群表現（雙線性 ＋ Steinberg，共 (p−1)² 個生成元）送入 Smith 標準形，
三例皆得**平凡群**。交叉檢查：Matsumoto（K₂ ≅ K^M₂ 對任意域）＋ Quillen（K₂(F_q) = 0）給出的正是 0。
故以計算為準，並把此教訓寫進報告行 T477——**猜想必須讓位於可重跑的計算**。
