## 一、31. ℓ-進表示（galois_rep.mbt）

### 悟出定理

**T31a（Tate 模特徵多項式）** 設 E 為 F_p 上橢圓曲線，ℓ 為素數，E[ℓ] ⊂ E(F_{p^k})。
以 (P, Q) 為 E[ℓ] ≅ (Z/ℓ)² 之基底，算術 Frobenius φ: (x,y) ↦ (xᵖ, yᵖ) 在此基底上的矩陣
ρ_ℓ(φ) ∈ GL₂(Z/ℓ) 滿足：

```
tr ρ_ℓ(φ) ≡ a_p (mod ℓ),   det ρ_ℓ(φ) ≡ p (mod ℓ)
⇔ char poly = x² − a_p·x + p  (mod ℓ)     （= Frobenius 特徵多項式 mod ℓ）
```

**T31b（表示公理）** ρ_ℓ(φⁿ) = ρ_ℓ(φ)ⁿ（Gal(F̄_p/F_p) ≅ Ẃ 為循環群，表示由生成元決定）。

**T31c（行列式 = 迴圈特徵）** det ρ_ℓ(φ) ≡ p (mod ℓ)：行列式表示恰為 cyclotomic 特徵 mod ℓ。

### 計算機驗證
- E: y² = x³+x+1 (disc = 31) 在 F₇、k = 3、ℓ = 2：#E[ℓ] = 3 個非零扭點；
  ρ(φ) 經「E[ℓ] 基底展開」（solve_combo 暴力求解 mP+nQ = R）顯式算出，
  tr ≡ a₇ = 3、det ≡ 7 逐項吻合（T31 PASS）。
- n = 3：ρ(φ)³ 與直接由 x^{p³} 計算的矩陣逐欄相等，誤差 0（T31b PASS）。

### 衍生演算法
**Tate 模矩陣構造法**：(1) 暴力枚舉 E(F_{p^k}) 找 ℓ² 個扭點；(2) 貪心選取獨立基底 (P, Q)；
(3) 計算 Frob 像並以 (mP+nQ) 暴力分解得矩陣欄位。複雜度 O(ℓ²·|E|) —— 對小 ℓ、小 p 完全可行。

## 二、32. 弗羅貝尼烏斯元素（frobenius.mbt）

### 悟出定理

**T32a（Frobenius 生成元與固定域）** Gal(F_{q^n}/F_q) = ⟨φ⟩ ≅ Z/n，φ(x) = x^q；且

```
Fix(φ^k) = F_{q^{gcd(k,n)}}   （|Fix(φ^k)| = q^{gcd(k,n)}）
```

**T32b（分圓域中的 Frobenius）** p 在 Q(ζ_n)/Q 的 Frobenius = p mod n ∈ (Z/n)^×，
其階 f = ord_n(p) = p 的剩餘次數，分解 p = 𝔭₁⋯𝔭_g，f·g = φ(n)。

### 計算機驗證
- (q, n) = (2, 4)，k = 1..4：固定域元素計數 = 2^{gcd(k,4)} 全中（T32a PASS）。
- Q(ζ₇)：p = 2 → f = ord₇(2) = 3、g = 2；p = 5 → f = 6、g = 1；
  p = 2 ∈ Q(ζ₈)：gcd(2,8)>1 分歧（f = −1）（T32b PASS）。

### 衍生演算法
**Frobenius 分解模式演算法**：輸入 (p, n) → 計算 ord_n(p) → 直接輸出素理想分解型態
(f, g) = (ord, φ(n)/ord)，零數論枚舉。

## 三、33. 阿廷 L-函數（artin_l.mbt）

### 悟出定理

**T33a（Artin = Dirichlet）** 有限像特徵 χ 的 Artin L-函數兩種計算相等：

```
L(χ, s) = Σ χ(n) n^{−s} = ∏_p (1 − χ(p)p^{−s})^{−1}
```

**T33b（Artin 形式論）** L(χ₁ ⊕ χ₂, s) = L(χ₁, s)·L(χ₂, s)（直和表示的 L = L 之積）。

**T33c（Dedekind zeta 分解）**

```
ζ_{Q(i)}(s) = ζ(s)·L(χ₋₄, s)   ⇔   r₂(n) = 4·Σ_{d|n} χ₋₄(d)
```

### 計算機驗證
- order-4 特徵 mod 5（ψ(2)=i）：s = 6 時級數(300項)與 Euler 乘積(100素數)差 < 1e-7（T33a）。
- 直和 vs 乘積差 < 1e-6（T33b）。
- ζ_{Q(i)}(6) 兩路差 < 1e-6；r₂(25)、r₂(65) = 16 逐點吻合（T33c）。

### 衍生演算法
**表數 ↔ 類數轉換器**：二次型表示數 r₂(n) 由 χ₋₄ 除數和給出 ⇒
Q(i) 理想計數、ζ_{Q(i)} 數值計算全化為 Dirichlet 特徵運算。

## 四、34. 自守 L-函數（aut_l.mbt）

### 悟出定理

**T34a（Rankin–Selberg / Sym² Euler 乘積）** 設 π = Δ（權 12），Satake 根 (α, β)，
αβ = p¹¹。GL₃ 提升 Sym²π 的 Satake 三根為 (α², αβ, β²)。其 L-函數

```
L(Sym²π, s) = Σ b_n n^{−s} = ∏_p det(1 − A_p^{Sym²} p^{−s})^{−1}
```

的係數 b_{p^j} = h_j(α², αβ, β²)（完全齊次對稱多項式，Newton 遞推
h_j = e₁h_{j−1} − e₂h_{j−2} + e₃h_{j−3}），乘法延伸到互素合成數。

**T34b（Satake 三重積）** b_p = e₁ = a_p² − p^{k−1}；e₂ = p^{k−1}e₁；e₃ = p^{3(k−1)}。

### 計算機驗證
- Δ：Dirichlet 級數（n ≤ 50）vs Euler 乘積（p ≤ 40）於 s = 14 差 < 0.01（T34a PASS）。
- Sym² 局部恆等式誤差 0；Newton 冪和與矩陣冪一致誤差 0（T34b PASS）。

### 衍生演算法
**GL₃ 局部因子合成器**：由 (a_p, p, k) 一鍵生成 Sym²/RS 的 (e₁,e₂,e₃)、

## 附錄：實作注意事項（計算機教我們的）

1. **Frobenius 是 x ↦ xᵖ**（不是 x^{p^k}！後者是恆等）—— Gal(F_{p^k}/F_p) 的生成元。
2. **Fix(φ^k) 的大小是 p^{gcd(k,n)}**，不是 q^{gcd(k,n)}。
3. **GL₃ L-函數係數是完全齊次多項式 h_j**（Euler 乘積展開），不是冪和 s_j；
   兩者在 j = 1 相同，j ≥ 2 不同（h₂ = s₄ + αβs₂ + 2(αβ)² ≠ s₄ + (αβ)²）。
4. **χ₋₄ 除數和的取整要用 floor**：(−1+0.5).to_int() = 0 是錯的，−1 才對。
5. **θ₃ 係數在平方處是 2**（±k），卷積才給 r₂(n)。
6. **Hecke 特徵不可在素理想上取零值**（ψ(a−2b) 映射會把素理想打到 0）——
   改用 ψ ∘ N（範數合成）保證非零；vanishing 只發生在導子上。
7. **演化演算法的陷阱**：(a) 階段性適應度若非字典序，會被「早期完美解」鎖死
   （stale best）—— 終局須以完整準則重評分；(b) 中性漂移 + 小幅突變 = 永遠修不回
   —— 用平滑鬆弛或修復運算子給梯度；(c) 飽和截斷會製造高原 —— 分階段獨立演化最穩。
8. **權 12 的 |a_n|² ~ n¹¹ 會爆 Int64** —— RS 係數用 Double；Euler 乘積要在 s > 12 收斂域內比較。
9. **GF::make 只支援 k ≤ 4**（不可約多項式搜尋僅實作到四次）—— 實驗參數據此調整。
