# 批次十一定理目錄（T381–T410、A57–A64、H11-1–H11-6、N11-1–N11-5）

主題：把 21 個拓撲斯／導出幾何／非交換幾何概念落成**可執行判定器**——豪斯多夫拓撲斯、
局部／平展／連通幾何態射、句法遺址、泛模型、卡拉梅洛橋樑、相干函子、微分凝聚拓撲斯、
依賴乘積、主 G-叢、緊拓撲斯、六運算形式體系、帶緊支撐直像、反常層、ℓ-進層、cdh 拓撲、
單純形層、(∞,1)-幾何態射、導出範疇、非交換拓撲斯。

目標：**類智能體湧現**——每個概念都要有「給輸入即回傳判定與整數見證」的函式，且判定器
必須能被負見證否證（非恆真）。

執行方式：`moon test`（176/176）與 `moon run cmd/main`（報告零 `[FAIL]`）。

## 計算模型

* **有限空間站**：有限拓撲空間 `X` 的非空開集族 = 站物件，包含關係 = 態射；覆蓋 = 聯集覆蓋。
* **有限預層 `B8PS`**：逐物件元素表 + 限制映射；`b11_ps_family` 由逐物件大小構造**非恆定**樣本層。
* **幾何態射**：`B8Fun`（物件映射 + 態射映射），恆等、3→2 滿射、2→3 單射三族。
* **Čech／神經引擎**：子集遮罩枚舉單純形，模 `p` 高斯消去算上同調；另有有序（允許退化）Čech 複形。
* **有限群作用**：`B9Group`／`B9GSet`，軌道、穩定子、指數子群共軛類、置換窮舉。

## 框架假設與限制

* **H11-1**（限制）有限站上緊性恆成立 ⇒ 只能以覆蓋量化呈現，真緊性需無窮站。
* **H11-2**（限制）局部性以候選 `f^! = u^*` 檢定，僅在範疇等價時成立；真 `f^!` 需補集構造。
* **H11-3**（假設）ℓ-進係數取 `ℤ/5`、`ℤ/7` 截斷，ℓ 無關性在此截斷層面驗證。
* **H11-4**（假設）G-扭子同構類 ≅ H¹；以 `5^{h¹}` 計數並用平凡性判準交叉核對。
* **H11-5**（限制）凝聚串 `Π ⊣ Disc` 逐物件計數在有限站不閉合，僅 `Disc ⊣ Γ` 可核對。
* **H11-6**（假設）反常用中中間偏差公式，未構造 perverse t-結構的心。
* 另有 1 項計入框架限制者為批次層級的「有限站 + 有限群 + 模 p」總體框架。

## 負見證（判定器須能拒絕的案例，共 11）

* **N11-1** 僅 1 個空間豪斯多夫 ⇒ 豪斯多夫判定非恆真。
* **N11-2** 3→2 與 2→3 皆不連通 ⇒ 連通判定非恆真。
* **N11-3** 非等價態射上局部性失敗（滿射 false、單射 false）⇒ 局部判定非恆真，且嚴格強於平展性。
* **N11-4** 3→2 非真態射（`f_! ≠ f_*`）⇒ 真性判定非恆真。
* **N11-5** 離散全平凡／圓非平凡 ⇒ 分類判定非恆真。
* 另 6 項來自 T382（T₀ 商非單點）、T384（緊性無反例）、T387（`f_! ≠ f_*`）、T392（Ext 高階消沒）、T397（ℓ 無關）、T402（`Sub(1) ≠ 2^{|X|}`）。
