## 一、定理導出（T101–T110）

### T101 朗蘭茲 C-群（dual.mbt）
**結構**：根系資料（Cartan 矩陣 A、對稱化子 d、π₁、中心）。
**導出定理**：
1. **對偶對合** ^(^G)=G：Cartan 轉置兩次復原；|π₁(G)|↔|Z(G^∨)| 交換兩次復原（SL₂ 實測）。
2. **π₁ ↔ 中心對換**：dual(SL₂) = (π₁=2, Z=1) = PGL₂ ✓。
3. **長短根互換**：B₂（Cartan [[2,−1],[−2,2]]、symm (2,1)）對偶 = C₂（[[2,−2],[−1,2]]、symm (1,2)）——轉置＋d′=∏d/d_i。
4. **外爾群階**：反射矩陣 s_i(e_j)=e_j−A[i][j]e_i 生成閉包：|W(A₁)|=2、|W(A₂)|=6、|W(B₂)|=8（BFS 矩陣閉包，與 Coxeter 理論一致）。
5. **對稱化可解性**：d_i A_ij = d_j A_ji 全矩陣驗證。

### T102 代數自守表示（autalg.mbt）
**結構**：S_k(SL₂(Z)) = Δ·{E₄^a E₆^b}，整基底；Hecke 整矩陣作用。
**導出定理**：
1. **Hecke 代數交換**：[T₂, T₃] = 0（S₂₈ 上 2×2 矩陣恆等式）。
2. **代數整性**：T₂, T₃ 矩陣整係數；特徵多項式 x² − tr·x + det 之 tr, det ∈ Z ⇒ Hecke 特徵值為代數整數。
3. **權空間維數**：dim S₁₂ = 1、dim S₂₈ = 2 = dim M₁₆（單項式計數 4a+6b=m）。
4. **Ramanujan 界**：S₂₈ 的 T₂ 特徵值（由特徵多項式求根）|λ| ≤ 2·2^{13.5} = 2^{14.5} ✓；T₂Δ = τ(2)Δ、τ(2) = −24 ✓。
**實作要點**：基底 q-展開非三角（皆自 q¹ 起），座標求解須用高斯消去而非逐項前代。

### T103 動機伽羅瓦群（motivic.mbt）
**結構**：Artin 動機 M_K ⇔ Gal(K/Q)；Frobenius 循環型 = 模 p 分解型態（Dedekind）。
**導出定理**：
1. **G_mot(x³−2) = S₃**：p ≤ 200（去掉壞素數 2, 3）觀測到全部三型態 {1³, 1·2, 3}；**1·2 的出現排除 A₃**（決定性證據）。
2. **G_mot(x²−5) = Z/2**：型態 {1², 2}。
3. **ζ_{Q(ζ₇)} 係數恆等式**：Σ_χ χ(p)（六個 mod-7 Dirichlet 特徵之和）= #{f=1 素理想}：p≡1 mod 7 時 = 6、否則 0——12 個素數逐一驗證（χ 由 ω = e^{2πi/6} 複數冪計算，免三角函數）。

### T104 霍奇-泰特分解（hodgetate.mbt）
**結構**：filtered φ-module；Newton 多邊形（由係數 p-adic 賦值下凸包）vs Hodge 多邊形。
**導出定理**：
1. **HT 維數**：Σh_i = dim V（E：(0,1) → 2）。
2. **弱可容許**（Mazur 不等式）：t_H = t_N 且 Newton ≥ Hodge（部分和）：普通 E 坡 (0,1) 相等；超奇 E 坡 (1/2,1/2) 上凸 ✓；(−1,2) 總和相等但部分和違反 → 拒絕 ✓。
3. **Newton 多邊形演算法**：x² − t x + p 的特徵值賦值 = 下凸包斜率取負：v(t)=0 → (0,1)；v(t)≥1 → (1/2,1/2)（精確有理輸出）。

### T105 德拉姆伽羅瓦表示（derham.mbt）
**結構**：D_dR = H¹_dR（超橢圓曲線 y²=f(x)）；Hodge 過濾。
**導出定理**：
1. **比較定理維數**：dim D_dR = 2g = rank H¹_et：y²=x⁵+x+3 → g=2、{x^i dx/y} 基底恰 2 個 holomorphic 微分。
2. **過濾跳躍**：(Fil⁰, Fil¹, Fil²) = (2g, g, 0) ⇒ h^{0,1} = h^{1,0} = g。
3. **Serre 對偶/辛配對**：genus-1 杯積矩陣 [[0,1],[−1,0]]，det = 1 ≠ 0（非退化）。

### T106 半穩定伽羅瓦表示（semistable.mbt）
**結構**：filtered (φ, N)-module；Tate 曲線模型 N = e₁₂、φ = diag(1, p)。
**導出定理**：
1. **Frobenius–monodromy 關係**：Nφ = pφN ⇔ p·φN = Nφ（矩陣恆等式，等價形式雙向驗證）。
2. **結晶判準**：crystalline ⟺ N = 0；ker N = D_cris 維度 1，商 1，1+1 = 2 = dim V。
3. **p-adic 單值定理（玩具）**：HT 權重 {0, −1} ∈ Z ⇒ 德拉姆（Sen 算子整數譜）。

### T107 完備化上同調（completed.mbt）
**結構**：退化映射系統（α^*, β^*, α_*, β_*）＋塔增長表。
**導出定理**：
1. **退化四恆等式**：α_*α^* = β_*β^* = p+1、α_*β^* = β_*α^* = 1 —— **秩計數引理**：四式全作用於小空間 H_n 時必然 dim H_{n+1} > dim H_n（2×2 塊矩陣行列式矛盾）；構造顯解 H_n=Q、H_{n+1}=Q²：α^*=(1,0)ᵀ, β^*=(0,1)ᵀ, α_*=(p+1,1), β_*=(1,p+1) ✓ 四式全成立＋維度增長 ✓。
2. **Hecke 交換**：T_m、T_n 作為共同矩陣之多項式必交換（companion 模型驗證）。
3. **2-塔增長**：g(X₀(2ⁿ)) = 0,0,0,1,2,5（n=1..6，古典表核對，秩 2g 非降）。

### T108 卡拉亞尼-朔爾策消滅（cs_vanish.mbt）
**結構**：Hecke Ramanujan 篩（尖性譜分離器）。
**導出定理**：
1. **譜分離**：權 12：|E₁₂(2)| = 2049 > 界 2·2^{5.5} = 90.5 > |τ(2)| = 24 —— Eisenstein 譜與尖譜被 Ramanujan 界一刀分開。
2. **H⁰/H² 消滅（玩具）**：trivial/Tate 譜 a_p = 1+p、p 均 > 2√p（p ≥ 5）⇒ 非中間次數 Hecke 模不含 Ramanujan 譜 ⇒ 尖投射子消滅之。
3. **篩法判定器**：`ramanujan_classify` 對 p = 2,3,5,7,11,13 兩側特徵值分類全對。

### T109 局部-整體相容性（localglobal.mbt）
**結構**：X₀(11) 兩側局部因子比對（自動側 q-展開 vs Galois 側點數）。
**導出定理**：
1. **兩側匹配**：a_{p^j}^{aut} = p^j + 1 − #E(F_{p^j})：全部好素數 p ≤ 47、j ≤ 3（42/42 一致）。
2. **壞素數 Steinberg**：p=11：a_{11^n} = a_{11}^n = 1（乘法約化），Galois 點數與 q-展開一致。
3. **行列式/循環特徵遞推**：a_{p²} = a_p² − 2p = tr(φ²)。
**實作要點（重要）**：power sums s_j = α^j+β^j 遞推的起始值是 **s₀ = 2**（α⁰+β⁰），非 Hecke 的 T_1 = 1——差一個 p·(s₀−T_1) 導致 j=2 全線錯位。

### T110 拉福格全域參數化（lafforgue.mbt）
**結構**：Carlitz A-模（A = F_p[t]）＋函數域 GL₂ zeta 分解。
**導出定理**：
1. **Carlitz 模組律**：C_a ◦ C_b = C_{ab}：以 **迭代定義** C_a = Σa_i·C_t^{∘i}（C_t(x) = τx + x^q）在 F₃²、F₅ 全點驗證 ✓（F_p-線性 ⇒ 合成＝係數捲積＝多項式乘法，三者一致）。
2. **P¹ ζ-函數**：Σ(qⁿ+1)uⁿ = 1/(1−qu) + 1/(1−u)（原始計數級數；Weil zeta 為其指數）。
3. **GL₂ L-因子 = Satake = Frobenius**：L(u) = 1 − a₁u + qu² = (1−αu)(1−βu) ⟹ 級數恆等式 **L(u)·A(u) = 2 − a₁u**（A(u) = Σs_n u^n）——Lafforgue 參數化在 GL₂ 顯例的完整驗證（E/F₅）。

## 四、附錄：實作注意事項（第三批新增教訓）

1. **q^n 點數**：暴力 (x,y) 雙層枚舉 O(q²) 會在 q = p³ 爆掉；奇特徵下用二次公式＋χ(disc)：#solutions = 1 + χ(B²−4C)，O(q) 完成（char 2 保留暴力）。
2. **GF::make 僅支援 k ≤ 4**（gf_poly_irreducible 限制）：count_points(p, k) 的 k 不可超過 4；函數域 zeta 驗證把 n 限到 3。
3. **power sums 起始 s₀ = 2**（見 T109 要點）；Hecke T_{p^j} 遞推的 T_{p⁰}=1 與 trace 遞推的 s₀=2 不同源，混用必錯。
4. **退化四恆等式不可同秩**：rank 證明（2×2 塊矩陣 det ≠ 0 vs rank ≤ n）說明完備化系統必須維度增長——本身即一條導出引理。
5. **Weil zeta vs 原始計數級數**：Z(u) = exp(Σc_n uⁿ/n)；原始 Σc_n uⁿ ≠ P(u)/((1−u)(1−qu))——級數恆等式要寫成 L(u)·A(u) = 2 − a₁u 型。
6. **Carlitz 模組律用迭代定義驗證**，不要用未加 τ^{[i]} 扭的係數公式（會與 C_t(x)=τx+x^q 不相容）。
7. **雙特徵值檢驗**：2×2 矩陣的對角元不是特徵值；Ramanujan 界檢驗須解 tr/det 二次式。
8. **根系對偶的對稱化子**：d′_i = (∏d)/d_i 交換長短根；symmetrizability 用 d_iA_ij = d_jA_ji 雙向驗證。
9. **MoonBit 新版**：`String::substring` 已棄用 → `s[i:j]`；`Double::powf/cos/sin` 不存在 → 自寫 sqrt/冪或複數乘法求單位根。
